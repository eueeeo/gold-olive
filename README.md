# Gold Olive

Веб-сайт компании по производству и поставке натурального оливкового масла первого холодного отжима из региона Измир (Турция). Проект реализован на чистом стеке веб-технологий (HTML5, CSS3, JavaScript) без сторонних библиотек и фреймворков.

## Основные разделы и возможности

### Главная страница (`index.html`)
- Промо-блок с навигацией и переходом к каталогу
- Блок с информацией о производстве и стандартах качества
- Популярные позиции с возможностью быстрого добавления в заказ
- Блок параметров качества и контроля кислотности партии

### О компании (`about.html`)
- Миссия и технологические стандарты мануфактуры
- Хронологическая шкала развития производства с 2019 года
- Раздел ключевых специалистов мануфактуры с инициальными аватарами

### Каталог продукции (`catalog.html`)
- Карточки товаров с ценами в турецких лирах (₺), описанием и визуальными изображениями
- Интерактивная фильтрация товаров по категориям в реальном времени:
  - Все товары
  - Классическая серия (стеклянные бутылки 0.5 л)
  - Семейный формат (жестяные канистры 5 л, бутылки с ручкой 2.5 л, боксы bag-in-box 3 л)
  - Подарочные наборы (дегустационные сеты, шкатулки ручной работы, премиальные фигурные бутылки)
- Кнопки добавления выбранного товара в корзину и быстрый переход к оформлению заказа

### Фотогалерея производства (`gallery.html`)
- Адаптивная сетка 3x4 из 12 фотокарточек производственного цикла (сбор урожая, раскладка сетей, проверка плодов, оливковые сады, дегустация)
- Встроенный интерактивный модальный просмотрщик (Lightbox):
  - Полноразмерное отображение снимков
  - Навигация кнопками «Назад» и «Вперёд»
  - Управление с клавиатуры (стрелки влево/вправо, клавиша Escape)
  - Закрытие по кнопке или клику вне области изображения

### О регионе и климате (`country.html`)
- Интерактивная географическая SVG-карта Турции с делением на климатические зоны
- Интерактивное переключение и подсветка регионов по клику, наведению и клавишам
- Динамический вывод климатических характеристик, температурных режимов и особенностей выращивания оливок
- Обзор преимуществ эгейского терруара и логистики порта Измир

### Контакты и оформление заказа (`contacts.html`)
- Интерактивная корзина покупок с расчетом общей суммы
- Управление количеством позиций (+ / -) и удаление товаров
- Автоматическое сохранение корзины и черновика заказа в localStorage
- Валидация полей формы (имя, телефон, адрес доставки, выбор способа оплаты)
- Защита от XSS-уязвимостей при обработке пользовательского ввода
- Интерактивный аккордеон с часто задаваемыми вопросами (FAQ)
- Блок отзывов покупателей с формой добавления нового отзыва и сохранением в localStorage

## Особенности реализации
- **Темы оформления:** светлая и тёмная темы с плавным переключением и сохранением выбора в localStorage
- **Адаптивность:** резиновая вёрстка для мобильных устройств, планшетов и широкоформатных мониторов
- **Доступность (a11y):** полная навигация с клавиатуры (`tabindex`, `role="button"`, обработка `Enter` и `Space`), атрибуты `aria-label` и `aria-expanded`
- **Без сторонних библиотек:** интерфейс и логика реализованы на нативном DOM API и JavaScript ES6+

## Стек технологий
- **Разметка:** HTML5 (семантические теги)
- **Стили:** CSS3 (CSS Grid, Flexbox, Custom Properties / CSS Variables)
- **Скрипты:** Vanilla JavaScript (ES6+, DOM API, Web Storage API)

## Установка и запуск

Проект работает без сборки и сторонних зависимостей.

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/eueeeo/gold-olive.git
   cd gold-olive
   ```

2. **Запустить сайт:**  
   Открыть `index.html` в браузере или запустить локальный сервер:
   ```bash
   npx serve .
   ```
