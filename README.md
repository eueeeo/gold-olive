# Gold Olive

Веб-сайт компании по производству и поставке натурального оливкового масла первого холодного отжима из региона Измир (Турция). Проект реализован на чистом стеке веб-технологий (HTML5, CSS3, JavaScript) без использования сторонних библиотек и фреймворков.

## Основные возможности

### Страницы и интерфейс
- **Главная (`index.html`):** промо-блок с навигацией, блок стандартов производства, популярные позиции каталога и блок контроля качества
- **О компании (`about.html`):** хронология развития мануфактуры с 2019 года и карточки специалистов
- **Каталог продукции (`catalog.html`):** фильтрация товаров по категориям в реальном времени, карточки продукции с ценами и быстрым добавлением в корзину
- **Фотогалерея (`gallery.html`):** адаптивная сетка снимков производственного цикла с интерактивным просмотрщиком (Lightbox) и управлением с клавиатуры
- **Регион и климат (`country.html`):** интерактивная географическая SVG-карта Турции с делением на климатические зоны, подсветкой и выводом характеристик
- **Контакты и заказ (`contacts.html`):** оформление заказа с валидацией, корзина покупок, интерактивный аккордеон FAQ и форма отзывов

### Особенности реализации
- **Корзина покупок:** расчет стоимости, изменение количества позиций и сохранение состояния заказа в `localStorage`
- **Темы оформления:** светлая и темная темы с сохранением выбора пользователя
- **Интерактивная SVG-карта:** переключение зон по клику и с клавиатуры с выводом описания терруара
- **Доступность (a11y):** навигация с клавиатуры (`tabindex`, клавиши `Enter`, `Space`, `Escape`), атрибуты `aria-label` и `aria-expanded`
- **Без сторонних библиотек:** вся логика и интерфейс реализованы на стандартном DOM API и JavaScript ES6+

## Стек технологий

- **Разметка:** HTML5 (семантическая структура)
- **Стилизация:** CSS3 (CSS Grid, Flexbox, CSS-переменные для тем оформления)
- **Логика:** Vanilla JavaScript (ES6+, DOM API, Web Storage API, события)

## Установка и запуск

Проект работает без сборки и сторонних зависимостей.

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/eueeeo/gold-olive.git
   cd gold-olive
   ```

2. **Запустить сайт:**  
   Открыть `index.html` в браузере или запустить локальный статический сервер:
   ```bash
   npx serve .
   ```
